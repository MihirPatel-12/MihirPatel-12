## Projects

### Asynchronous FIFO Design and Verification

Designed and verified an asynchronous FIFO using Verilog/SystemVerilog.

- Implemented CDC-safe FIFO architecture using Gray-code synchronization
- Developed a layered SystemVerilog verification environment
- Used generator, driver, monitor, scoreboard, mailbox, and virtual interface components
- Applied constrained-random and coverage-driven verification
- Achieved 390/390 passing checks with high functional coverage

[Repository](https://github.com/MihirPatel-12/asy-fifo-verification)

### Scan-Based DFT and ATPG Implementation

Implemented a scan-based DFT and ATPG flow for a synchronous FIFO using Cadence tools.

- Implemented muxed scan insertion
- Performed scan-chain stitching
- Generated stuck-at ATPG patterns
- Analyzed fault coverage using Cadence Genus and Modus
- Achieved 99.98% adjusted stuck-at fault coverage

[Repository](https://github.com/MihirPatel-12/Scan-Based-DFT-and-ATPG-Implementation-of-synchronous-FIFO-using-Cadence-tools)

### RISC-V Processor with Custom AES Instruction Set

Designed a RISC-V processor with a custom AES instruction-set extension.

- Designed a custom instruction for AES-128 encryption
- Implemented a fully unrolled 10-round AES-128 datapath
- Achieved single-cycle AES-128 execution latency
- Verified functionality using the FIPS-197 known-answer test
- Performed cycle-accurate RTL simulation using Xilinx Vivado

[Repository](https://github.com/MihirPatel-12/RISC-V-Processor-with-Custom-AES-Instruction-Set)
